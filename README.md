# Gerencial Skyline

Painel gerencial em **React**, projeto paralelo ao dashboard de produção e à lista de preços.

Usa os **mesmos endpoints** do Skyline Dashboard / NR Timeline (recebimento, reparo e peças). Layout no visual da NR Timeline / NR Itens.

## Link público (GitHub Pages)

**https://essouzas21-sketch.github.io/skyline-gerencial/**

## Rodar local

```bash
npm install
npm run dev
```

Abra `http://localhost:5174/`.

O primeiro load baixa o webhook de reparo (pode levar alguns minutos).
